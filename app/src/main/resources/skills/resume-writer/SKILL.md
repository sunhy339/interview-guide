# 简历成稿 Skill

## 目标

把用户确认过的个人信息、教育经历、工作经历、项目经历和技能整理成可直接审阅和导出的简历成稿。

## 写作规则

1. 只使用用户提供或已经确认的事实，缺失内容用“待补充”列出，不要猜测。
2. 默认结构为：基本信息、求职目标、职业概览、工作经历、项目经历、专业技能、教育经历和补充信息。
3. 项目经历使用统一格式：项目名称｜角色｜时间；项目背景；个人职责；技术方案；结果与指标。
4. 每条经历尽量以动词开头，减少空泛形容词，避免重复描述同一项能力。
5. 输出适合导出的纯文本结构，标题层级清晰，列表和段落长度适合中文简历排版。
6. 在生成成稿前，列出可能存在事实风险的句子，让用户确认后再导出文件。

## 最终输出

- 简历标题和目标职位
- 完整简历正文
- 事实待确认项
- 导出建议：Word 适合继续编辑，PDF 适合投递
