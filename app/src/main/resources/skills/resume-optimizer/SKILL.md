# 简历优化 Skill

## 目标

帮助用户把已有简历改得更清楚、更有证据、更贴合目标岗位，同时保留真实经历，不凭空添加项目、技术、数字或任职经历。

## 工作方法

1. 先识别目标岗位、简历已有事实、缺失信息和用户希望改进的部分。
2. 按“问题 -> 修改理由 -> 建议版本 -> 需要用户确认的事实”输出。
3. 项目经历优先使用“动作 + 技术方法 + 结果”的结构；没有真实数字时使用可验证的结果描述，并标注需要补充数据。
4. 保留原文事实边界。不能把推测、通用职责或岗位要求写成用户已经完成的工作。
5. 给出 ATS 友好的关键词建议，但避免关键词堆砌；关键词必须和经历或目标岗位有关系。
6. 先产出可审阅的修改稿，用户确认后再生成 Word 或 PDF。

## 输出结构

- 简历整体问题
- 本次修改范围
- 修改前后对照
- 需要用户确认的事实
- 下一步可导出的简历正文
